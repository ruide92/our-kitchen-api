## PA-01 首页进入推荐

**用户故事**: 用户打开小程序，想知道今晚吃什么。

**步骤**:
1. 首页加载完成，显示家庭信息和四个快捷入口
2. 点击「随机菜谱」
3. 进入「今天吃什么」页面，自动加载推荐
4. 页面显示：餐次/人数、模式切换（均衡/冰箱优先/换口味）、数量选择（1-4道）
5. 推荐结果显示菜名、烹饪时间、推荐理由标签

**验收标准**:
- [ ] 首页「随机菜谱」可点击，无 toast placeholder
- [ ] 推荐页面自动加载，不显示空白
- [ ] 加载中有 loading 状态
- [ ] 推荐失败有错误提示 + 重试按钮
- [ ] 无推荐时显示 empty 状态，不报错

## PA-02 推荐加入菜单

**用户故事**: 用户看到推荐结果，决定就吃这些。

**步骤**:
1. 在推荐页面，可点击「锁定」保留某道菜
2. 点击「换一批」重新推荐（锁定菜保留）
3. 点击某道菜 → 进入菜谱详情页
4. 详情页点击「加入本餐」→ toast 成功
5. 返回推荐页，点击「就吃这些」→ 批量加入当前餐
6. 自动跳转到本餐菜单页，菜已在列表中

**验收标准**:
- [ ] 锁定/解锁切换正常
- [ ] 「换一批」保留锁定菜
- [ ] 推荐→详情跳转携带正确 recipe_id
- [ ] 详情页「加入本餐」使用正确餐次（mealTarget 同步）
- [ ] 「就吃这些」批量加入，部分失败有提示
- [ ] 加入后跳转菜单页，菜可见
- [ ] 重复加入不产生重复行（ALREADY_IN_MEAL 处理）

## PA-03 冰箱推荐闭环

**用户故事**: 用户想看看冰箱里的食材能做什么。

**步骤**:
1. 首页点击「看冰箱做菜」→ 切换到冰箱 Tab
2. 冰箱页底部「看冰箱做菜」按钮 → 弹出推荐 sheet
3. 推荐列表显示：菜名、可做状态（可直接做/差少量/需采购）、食材已有数量
4. 缺食材的菜显示具体缺什么（名称+数量）
5. 点击「加入本餐」→ toast 成功 → 跳转本餐菜单页
6. 点击菜名 → 进入菜谱详情

**验收标准**:
- [ ] 首页入口可点击，正确切换到冰箱 Tab
- [ ] 推荐 sheet 弹出，无空白
- [ ] 可做状态准确（CAN_COOK_NOW / MISSING_FEW / NEEDS_SHOPPING）
- [ ] 缺食材显示名称和数量，不是 UUID
- [ ] 「加入本餐」成功后跳转菜单页
- [ ] 加入失败有错误提示
- [ ] sheet 关闭后 TabBar 恢复正常

## PA-04 周计划闭环

**用户故事**: 用户想提前规划一周的菜单。

**步骤**:
1. 首页「本周菜谱」区域点击「查看本周」→ 切换到菜单 Tab
2. 空状态显示「生成本周菜谱」按钮
3. 点击生成 → 创建 DRAFT，显示「本周安排 · 待确认」
4. DRAFT 状态显示：放弃修改 / 确认本周安排
5. 每道菜可：锁定/换一道/删除
6. 每餐可「重新安排」，每天可「重新安排今天」，全周可「重新安排本周」
7. 锁定的菜在重排时保留
8. 点击「确认本周安排」→ 变为 ACTIVE
9. ACTIVE 状态显示「重新安排本周」入口

**验收标准**:
- [ ] 空状态有生成 CTA，不是 placeholder
- [ ] 生成后是 DRAFT，不自动 ACTIVE
- [ ] DRAFT 标题明确标注「待确认」
- [ ] 锁定/换一道/删除 走真实 API，不是 toast
- [ ] 重排范围正确（MEAL 只改当前餐，DAY 只改当天，WEEK 改全周）
- [ ] 锁定菜在重排后保留且只出现一次
- [ ] 确认后旧 ACTIVE 被归档，新计划为 ACTIVE
- [ ] MEMBER 角色看不到编辑按钮

## PA-05 做饭完成扣库存

**用户故事**: 用户按照菜单做完饭，系统自动扣减冰箱库存。

**步骤**:
1. 本餐菜单页，菜已加入，状态为 PLANNING
2. 点击「确认菜单」→ 状态变为 CONFIRMED
3. 点击「开始做饭」→ 进入做饭视图，显示步骤
4. 点击「完成做饭」→ 弹出确认实际用量 sheet
5. sheet 显示每样食材：建议用量、当前库存、可修改实际用量
6. 点击「确认完成」→ 状态变为 COMPLETED
7. 冰箱库存对应食材数量减少

**验收标准**:
- [ ] PLANNING → CONFIRMED 状态切换正常
- [ ] CONFIRMED → COOKING 进入做饭视图
- [ ] 做饭步骤列表显示（无步骤时提示暂无步骤）
- [ ] 完成 sheet 显示可扣库存的食材
- [ ] 实际用量可修改
- [ ] 确认完成后状态为 COMPLETED
- [ ] 冰箱库存真实扣减（可在冰箱页验证）
- [ ] 不可扣库存的食材标注「不自动扣库存」

## PA-06 家庭喜欢影响推荐

**用户故事**: 家人收藏和评分的菜，在推荐中优先出现。

**步骤**:
1. 首页点击「家人喜欢的菜」→ 进入家人喜欢页面
2. 页面显示：菜名、家人喜欢指数、原因（几位收藏/谁评分/做过几次）
3. 点击某道菜 → 进入详情
4. 在详情页收藏/评分该菜
5. 返回推荐页面，使用「均衡推荐」模式
6. 被家人收藏/高分的菜在推荐中排名靠前

**验收标准**:
- [ ] 「家人喜欢的菜」入口可点击，进入真实页面
- [ ] 页面显示真实数据，无 fixture
- [ ] 喜欢指数有计算依据（收藏×5 + 评分×3 + 想吃×4 + 做过×2）
- [ ] 只统计当前家庭数据，不混入其他家庭
- [ ] 点击菜进入详情
- [ ] 收藏/评分后，推荐中该菜优先级提升
- [ ] 已删除的菜不出现在家人喜欢列表
